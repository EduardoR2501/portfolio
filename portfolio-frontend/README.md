# Frontend de portafolio personal

Esta carpeta contiene el código frontend de mi portafolio personal como desarrollador de software junior.

## Tecnologías utilizadas para frontend

- React
- TypeScript
- Vite

## Desarrollo local

### Requisitos

- Node.js
- npm

### Pasos para ejecutar el proyecto

```bash
npm install
```

```bash
npm run dev
```

La aplicación estará disponible en:

```bash
http://localhost:5173
```

## Variables de entorno

El frontend utiliza variables de entorno para su configuración.

Variables utilizadas:

- VITE_API_BASE_URL: URL base del backend

Las variables de entorno no se versionan y se definen en un archivo .env en la raíz del proyecto.

Ejemplo:

VITE_API_BASE_URL=http://localhost:3000
